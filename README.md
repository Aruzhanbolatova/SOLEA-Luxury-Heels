# SOLEA — Luxury Heels

SOLEA is a student frontend project dedicated to luxury footwear.
The website introduces designer brands, presents a shoe catalog,
and helps users explore their preferred pair.

## Live Website

https://aruzhanbolatova.github.io/SOLEA-Luxury-Heels/

## Pages

- Home — introduces SOLEA and its collections.
- Shop — displays the footwear catalog.
- Brands — introduces luxury footwear designers.
- Design your pair — helps users explore shoes based on their preferences.
- Size Guide — provides shoe sizing information.
- About us — presents the project and its concept.

## Technologies

- HTML5 — page structure and content.
- CSS3 — colors, typography, spacing, and layouts.
- Flexbox and CSS Grid — element arrangement.
- Bootstrap 5 — responsive layouts and interface components.
- Media queries — adjustments for different screen widths.
- JavaScript — interactive functionality.
- GitHub Pages — website hosting.

## Responsive Design

The website uses responsive layouts for mobile, tablet,
and desktop screens.

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using the Live Server extension.
4. Use the navigation menu to explore the pages.

Use a local web server so that features loading catalog data
can work correctly.
